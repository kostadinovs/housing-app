# Пријави проблеми — станбено домување

Веб-апликација за пријавување проблеми во зградата, со вистинска база (SQLite) на серверот — сите што ја отвораат страницата гледаат исти податоци.

## Содржина

- `server.js` — Node.js/Express сервер + API + SQLite база
- `public/index.html` — веб-страницата (форма, табови, коментари)
- `data.sqlite` — базата (се создава автоматски при прво стартување)

## Локално тестирање

Потребен е инсталиран Node.js (верзија 18 или понова).

```bash
npm install
npm start
```

Страницата ќе биде достапна на `http://localhost:3000`. Базата се зачувува во `data.sqlite` во истата папка — тргни го тој фајл ако сакаш да почнеш од чисто.

## Објавување на сопствен домен

Потребен ти е хостинг што поддржува **Node.js процес во позадина** (не обично споделено хостинг за статични HTML страници, бидејќи серверот мора постојано да работи). Опции, од најлесна до најевтина:

### Опција А — Render.com / Railway.app (најлесно, бесплатен план достапен)

1. Стави ги овие фајлови во Git репозиториум (на пр. GitHub).
2. На Render/Railway: "New Web Service" → поврзи го репозиториумот.
3. Build command: `npm install`, Start command: `npm start`.
4. Додади **Persistent Disk** (Render) или volume, монтиран на пр. на `/data`, и постави environment променлива `DB_PATH=/data/data.sqlite` — инаку базата се брише при секој нов deploy.
5. Кога сервисот е горе, во делот "Custom domain" го внесуваш својот домен (пр. `prijavi.mojazgrada.mk`) и го поставуваш CNAME записот кај регистраторот на доменот според нивното упатство.

### Опција Б — сопствен VPS (DigitalOcean, Hetzner, итн.)

1. Инсталирај Node.js на серверот.
2. Прекопирај ги фајловите (на пр. со `scp` или Git).
3. `npm install --production`
4. Стартувај го процесот трајно, на пр. со [pm2](https://pm2.keymetrics.io/):
   ```bash
   npm install -g pm2
   pm2 start server.js --name prijavi
   pm2 save
   pm2 startup
   ```
5. Стави **Nginx** (или Caddy) пред него како reverse proxy на порта 80/443, со SSL сертификат (бесплатно преку Let's Encrypt / Certbot или автоматски со Caddy).
6. Кај регистраторот на доменот, DNS `A` запис → IP адресата на серверот.

### Опција В — Docker (ако хостингот поддржува контејнери)

Во папката е вклучен `Dockerfile`:
```bash
docker build -t prijavi .
docker run -d -p 3000:3000 -v $(pwd)/data:/app/data -e DB_PATH=/app/data/data.sqlite prijavi
```
Секогаш монтирај volume за базата — инаку податоците исчезнуваат кога контејнерот ќе се рестартира.

## Важно за базата

- `data.sqlite` е обичен фајл — редовно прави резервна копија (copy на тој фајл).
- На хостинзи каде дискот не е трајно зачуван меѓу деплоеви (некои бесплатни планови), задолжително постави persistent disk/volume, инаку губиш податоци при секое ажурирање.

## Лозинка за бришење

Бришењето на пријава бара лозинка. Дефолтната е `1234` — задолжително смени ја пред да ја објавиш страницата, преку environment променлива:

```bash
DELETE_PASSWORD=твојата_нова_лозинка npm start
```

На Render/Railway/VPS ова се поставува во делот "Environment Variables" на сервисот, а не во кодот.

## Ако сакаш заклучување со лозинка

Апликацијата сега е отворена за секој што го знае линкот. Ако станарите/управата треба заедничка лозинка пред пристап, кажи ми — тоа е мало додавање (basic auth на серверот).
